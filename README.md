# Player Journey Visualization Tool

A web-based visualization tool for analyzing player behavior in LILA BLACK game.

## Live Demo
https://player-journey-tool-tcrvkydzetgjyccppkxumr.streamlit.app/

## Tech Stack
- Python
- Streamlit
- Plotly
- Pandas
- PyArrow
- Pillow

## Features
- Player journey visualization on minimap
- Human vs bot differentiation
- Kill, death, loot, storm death markers
- Filter by map, date, match
- Timeline playback
- Heatmaps for kill zones, death zones, traffic

## How to Run Locally
1. Clone the repository
2. Install dependencies: pip install -r requirements.txt
3. Run the app: streamlit run app.py
